# Delhi PM2.5 ADR project

Code, supporting data, reproducibility notes, and diagnostic outputs for a reduced-order two-dimensional advection–diffusion–reaction (ADR) study of PM2.5 over Delhi. The research paper is not included.

This repository is being populated with the solver, processing scripts, processed data, verification materials, and selected small raw inputs. Large raw CPCB/DPCC archives and the OSM GeoPackage are excluded from ordinary Git history; download links and checksums should be documented separately.

Important: solver verification establishes numerical correctness for the specified discrete model, not predictive validity or real-world policy effects. The supplied archive is missing some inputs and final uncertainty outputs; see the reproducibility notes when added.
